# WhoAmI Bible Quiz Editorial Quick Reference

> Accurate. Distinctive. Memorable. Fair

> This document is a quick reminder of the project's editorial standards. It complements, but does not replace, the full Editorial Guide.


---

# The Golden Rule

> **Infer only when Scripture leads to a single reasonable conclusion.**

If another careful Bible reader could reasonably disagree, rewrite or remove the clue.

---

# The Burden of Proof

The contributor must demonstrate that a clue is correct.

Reviewers should never be expected to prove a clue wrong.

---

# The Aha! Principle

Aim for:

> "I never noticed that before."

Avoid:

> "How was I supposed to know that?"

Reward understanding—not obscure trivia.

---

# Candidate Reduction

Every clue should meaningfully reduce the number of possible answers.

Difficulty comes from reasoning, not from obscure verses.

---

# Progression

- Start with familiar facts as easy clues.
- Gradually increase difficulty.
- End with rewarding synthesis (nightmare clues).

Every clue should reveal slightly more than the previous one.

---

# One Clue, One Idea

Each clue should communicate one memorable fact.

Avoid combining multiple unrelated ideas.

---

# First-Person Perspective

Always write as though the character is speaking.

Good: I built an ark.

Bad: Noah built an ark.

---

# State Facts, Not Interpretations

Describe what Scripture records.

Avoid theological conclusions or speculative language.

---

# Synthesis ≠ Interpretation

Synthesis combines biblical facts.

Interpretation adds meaning.

Prefer synthesis every time.

---

# Primary Evidence

Support every clue with the Scripture that most directly establishes it.

Include every passage needed for synthesis.

---

# Write Naturally

Use simple, conversational language.

Challenge biblical knowledge—not reading comprehension.

---

# Be Distinctive

Choose clues that meaningfully separate one candidate from another.

Specific beats generic.

---

# Avoid Redundancy

Every clue should contribute something new.

If two clues communicate the same idea, keep the stronger one.

---

# Balance Clue Types

Mix:

- Direct
- Narrative
- Relationship
- Characteristic
- Chronological
- Genealogical
- Synthesis

Variety creates better gameplay.

---

# Translation Standard

Within a dataset:

- Use one translation consistently.
- Use it for direct quotations, names, and citations.
- Most clues should summarise rather than quote Scripture.

---

# Editorial Mindset

Before accepting a clue, ask:

- Is it true?
- Can I prove it from Scripture?
- Is it distinctive?
- Is it enjoyable?
- Is it placed at the correct difficulty?
- Would I enjoy discovering this clue as a player?

---

# Remember

Good contributors write clues.

Great editors improve them.

The goal is not to create the hardest quiz.

The goal is to create the most rewarding one.
